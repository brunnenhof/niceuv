# Déforestation maximale

Les forêts, surtout les forêts tropicales, [sont déboisés dans le monde entier](https://www.globalforestwatch.org/dashboards/global/). Tu trouveras plus d'informations sur [sous](https://rainforests.mongabay.com). C'est grave pour plusieurs raisons :

1. Les forêts stockent environ la moitié de leur poids sous forme de CO2. Quand on les abat, ce CO2 est libéré dans l'atmosphère, ce qui aggrave le réchauffement climatique.
1. Le sol sur lequel elles poussent contient également beaucoup de CO2. Lorsqu’elles sont abattues, ce CO2 est lessivé et se retrouve dans les océans et dans l’air – ce qui est néfaste dans les deux cas. (Points bonus : sais-tu pourquoi ?)
1. Elles constituent de formidables refuges et habitats pour la biodiversité. Lorsqu’elles sont abattues, ceux-ci disparaissent.

Cette mesure te permet de réduire l'abattage ou même de l'arrêter complètement. 0 signifie qu'il n'y a aucune restriction sur l'abattage : tout se passe comme avant ; 10 = réduction de 10 % du volume maximal d'abattage, 50 = réduction de 50 % du volume maximal d'abattage, etc., jusqu'à une réduction de 90 %, ce qui équivaut pratiquement à une interdiction d'abattage.
