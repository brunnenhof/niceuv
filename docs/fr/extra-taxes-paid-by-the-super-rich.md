# Les impôts supplémentaires payés par les super-riches

Les taxes supplémentaires servent à soutenir certains groupes : dans une autre mesure, tu peux choisir cette option sur [Renforcer les femmes](female-leadership.md). C'est toi qui fixes ici le pourcentage des taxes **supplémentaires** payées par les propriétaires (les propriétaires paient eux-mêmes 50 % des taxes supplémentaires, même sur [TLTL](two-scenarios.md)). Par exemple, 90 signifie que les propriétaires paient 90 % des taxes supplémentaires,  70 signifie qu'ils paient 70 % des taxes supplémentaires, etc.
