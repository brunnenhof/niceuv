TO RE-SYNC APPROVED FILES FROM SERVER BACK TO LOCAL
rsync is the best tool for this — only transfers changed files on repeat syncs. Run from your local example/ folder in Git Bash or WSL:

# Pull reviewed + approval state from server → local
rsync -av pete@SERVER:/home/pete/niceuv/example/docs/fr_reviewed/ docs/fr_reviewed/
Or if you want the full docs folder (all language outputs):

rsync -av pete@SERVER:/home/pete/niceuv/example/docs/ docs/
Replace SERVER with the server's hostname or IP. The trailing slash on the source path matters in rsync — it means "copy the contents", not the folder itself.
rsync -av pete@206.168.213.171:/home/pete/niceuv/example/docs/fr_reviewed/ docs/fr_reviewed/
And to push local approved files back to the server after any local edits:
rsync -av docs/fr_reviewed/ pete@206.168.213.171:/home/p

If you're on Windows without WSL/Git Bash, scp from PowerShell works too but copies everything every time:

scp -r pete@SERVER:/home/pete/niceuv/example/docs/fr_reviewed/ docs/
